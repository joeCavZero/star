# Position Memory

For the **Star Virtual Machine**, position memory is a specialized area that stores the source code position for each instruction. This is crucial for debugging and error reporting, as it allows the assembler to provide accurate information about where in the source code an error occurred.

You can read more about how position memory is used for error reporting in the [generation stage documentation](/docs/generation-stage.md) and [execution stage documentation](/docs/execution-stage.md).
